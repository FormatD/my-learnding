# 本地模块化系统

采用 Vue 3 + TypeScript、ASP.NET Core 10、PostgreSQL 16。生产前端由同一个 API 服务提供，避免跨站会话与额外公开开发端口。

每个家庭变更在 PostgreSQL 事务内取得家庭 advisory lock，再执行幂等检查、可变对象版本检查、领域命令、审计与命令记录。该方案适合单家庭低并发，后续可缩小到学生锁；不得省略命令唯一约束。

内容发布保存完整不可变快照；学习会话保存 ReleaseId，发布新内容不重解释旧作答。评估更新重放整学生的固定事件序列，写入新世代与对应证据、掌握和日程后，同事务切换学生绑定。旧世代不参与活动计算。

参考设计的所有未来目标仍按 STATUS.md 跟踪；当前没有把模型分数当成经过验证的真实能力概率。

能力测量签名从行为、边界、类型及规范化覆盖要求确定性计算。注册新发布修订时与同一稳定身份的既有不可变定义比较；名称修订允许，签名改变拒绝。编辑器将已发布定义置为只读，提供新增独立能力入口。签名可从导出的完整发布定义重建，当前不以语义模型判断“含义是否相同”。
