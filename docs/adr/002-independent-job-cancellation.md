# ADR 002：独立任务取消事务

状态：采用，2026-10-04。依据设计§13.3的Cancelled状态与现有持久化租约/提交围栏。

执行器持有家庭锁进行整个领域计算，普通写入口使用同锁。取消沿普通入口会等待计算完成，失去取消意义。采用仅显式标记入口的独立控制事务：专用幂等锁、锁定并重新核对会话/成员、按家庭读取任务并检验具体角色，使用任务非键更新锁撤销提交权限。控制状态不递增内容Family.Version；其他领域写入协议不变。取消事实、准确响应与幂等Command原子保存。

取消成功说明任务的结果提交已被禁止；运行结束由执行器真正退出后另行确认。任务租约与结果完成仍在同一行锁围栏内，完成已提交后拒绝取消，取消胜出则旧结果回滚。模型调用Started独立保存前也检查领取许可，短共享锁与取消串行。任务停止不证明提供者物理调用停止，未知额度/账本继续保留，禁止自动释放。

可取消的是候选建库、PDF解析、映射准备及人工评估重建。原作答学习结果投影是必须完成的事实传播，不能被取消功能丢弃；明确拒绝并保留故障人工恢复。取消不等于删学习事实、撤销正式内容或通过审核。已取消恢复须明确新轮次，不悄悄重启。旧同步兼容入口收敛与独立事件/增量消费继续开放。

实现与证据见[运行手册](../runbooks/job-cancellation.md)及实际接口/执行器/浏览器验收，测试合成输入不代替正式试用。
