# 建库调用预算与负责人核对

当前只运行本地Mock，不接入付费服务。以下预算保护未来可验证报价的调用入口；受控计费夹具不能当作真实账单、模型质量或价格验证。

## 额度与窗口

GET /builder/budget返回本家庭当前策略及UTC日期窗口，ContentEditor可读。家庭负责人可PUT调整每日费用、每日Token、单次费用、单次Token和并发上限，必须保留调整依据；孩子及非负责人不能调整。默认费用/Token额度全部0、并发1，本地Mock明确无费用且无模型Token，仍需并发名额。GET在策略尚未保存时返回临时默认对象；第一次预留或负责人保存才建立实际策略，临时ID/创建时间不代表已持久化的历史。

费用目前只接受USD六位小数，单次不超过每日，Token上限非负且单次不超过每日，并发1～10。降低额度不取消或修改既有调用/预留，会阻止额度不足的新调用；重新处理检查当前策略，不沿用过去较宽策略。每次决策保存原策略快照、纯计算报价、UTC日期及预留；运行的ModelConfigHash仍只固定候选协议和资源上限，没有声称付费价格或家庭预算已经写进该配置。

提供者必须在实际Generate之前提供可验证的最大费用和最大Token报价；报价不得调用外部服务。独立事务取家庭预算锁、累计当前实际结算与未知预留、检查单次/每日费用及Token/并发，提交预留和Started后才允许提供者开始。两连接竞争也不能各自读取旧余额后重复消费。拒绝保存Denied及原因，不进入Generate；该记录没有实际调用费用或Token。

实际明确响应按可信金额和完整用量结算，释放剩余预留；无用量/费用保持未知。未知预留跨UTC日期继续计入，不能靠改日释放。原日期明确结算不计作今天费用。旧调用缺少可验证预留且费用/用量未知时阻止新的有费用调用，不推算旧费用为0。超出原报价的实际费用/Token保留原值并暂停后续调用，等待核对，不能把实际消费裁成上限。

## 未结束调用

Started、Failed或Cancelled不证明提供者已经结束，继续占名额，即使取消等待或工作进程已经退出。Returned表示收到响应，因此释放物理名额，但费用/Token未知时额度继续预留。没有自动过期或因进程重启清零。费用异常或名额不足会让原任务明确停止，预算问题不自动退避重试；完成核对或调整后可填写原因，使用原固定输入人工重新处理。通用租约/心跳及提供者自身取消确认尚未接入。

## 追加核对

负责人在调用账本填写调用已结束的确认、实际费用/完整Token、原因及账单或本地进程依据，POST /builder/calls/{id}:reconcile。必须先实际核对；勾选不能代替提供者证据。明确本地无费用报价且未出现确认计费时，核对使用0费用、货币/Token均NULL。其他调用要求USD费用和完整输入/输出Token；已确认USD费用及已确认用量不能降低或改写。非USD原始费用仍保留，没有自动换汇；负责人若提交USD核对，须由实际依据支持这一金额，系统不验证汇率。

一条调用只能追加一次核对，重复409；Denied或已经完整结算无需核对。新BuilderBudgetReconciliation保存负责人账户、ParentConfirmed来源、原因和依据，并与原调用同家庭绑定。原BuilderCall的状态、时间、费用/用量、未知值和原报价不回写；页面并列展示。人工核对是家庭确认，不能冒充提供者原始账单。尚未确认结束的调用不可据取消等待自行核对，真实外部提供者返回和账单对接仍须联调。

GET /builder/calls保留原分页字段，新增reconciliations是可选响应字段，旧客户端仍兼容。预算、调用、核对均纳入全家私有ZIP、加密快照和家庭删除/恢复最新删除清单。孩子拒绝读取/修改，跨家庭调用404。

## 验证与开放项

builder_budget_persistence_acceptance.py使用真实独立连接核对并发、每日/单次成本及Token门禁、跨日未知、人工核对不改原记录、缺旧上限、两连接抢同一费用余额及超报价暂停。builder_budget_api_acceptance.py核对负责人变更、无效/非负责人拒绝、明确结束及原因、追加一次核对、原记录不变和私有ZIP。真实进程终止专项现在也验证：仅Started时不会自动重试进入提供者，负责人追加受控本地核对后才重新执行。真实浏览器检查预算保存、本地不计费/Token不适用与人工审核发布。

仍须补齐固定提供者价格/最大请求Token和配置摘要、跨家庭账户总预算、通用Job租约/心跳、真实模型账单和质量；本地Mock及夹具不能关闭这些完整V1条件。
