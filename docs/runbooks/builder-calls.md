# 逐次建库调用账本

候选调用先在独立数据库事务保存BuilderCall.Started，再调用提供者；返回、失败或取消使用另一独立提交保存。原候选事务仍保护候选/索引/运行状态和BuilderAttempt的原子性，回滚不会删除已经发生的调用事实。调用账本以ExecutionId + CallNumber唯一，每次实际恢复执行创建新ExecutionId；进程中断时BuilderAttempt未提交而编号重复，并不说明物理调用没有发生。账本不宣称外部模型物理只调用一次。

记录实际RunId、重试轮次、尝试编号、调用序号、是否修复、提供者/型号、原输入/配置摘要、开始/完成时间、实际等待毫秒、返回摘要以及可用的用量/费用。返回只是收到提供者响应，不意味着候选通过结构/来源校验或人工审核。即使响应随后结构不合格或候选保存失败，返回事实与实际可信费用继续保留。当前提供者仅Mock，明确LocalNoCharge及0费用，Currency/输入输出Token为NULL表示不适用；没有用字符数伪造模型Token。

未来提供者可返回独立BuilderUsage；可信确认费用要求非负六位小数值及三字母货币，未知费用保持NULL，不与零费用混淆。输入/输出Token非负且可独立未记录；无用量响应保持Unknown。非法计费数据停止处理并保留调用开始和失败事实，不能作为已确认费用。不同货币没有自动相加或换算。

真实进程可能在开始后或响应返回与提交之间退出，留下Started与未知结果/费用；恢复会保留旧行并追加新执行，不能用候选回滚推断“未调用”。正常取消会尝试独立保存Cancelled及未知费用；若数据库不可用、进程退出或最终保存尚未完成，仍可能保留Started。取消等待不证明外部模型停止运行或不计费。旧运行没有逐次记录时不回填，不能推算历史Token或费用。

家长ContentEditor可用GET /builder/calls，按可选runId查询，默认每页20、最多50；跨家庭任务404、孩子403，页码/大小无效422。辅助建库页面显示调用、修复、返回状态及费用/用量事实，未知清楚标识；全家私有ZIP与加密数据库快照包含该表，家庭删除及恢复最新删除清单一起闭合。账本只保存返回摘要，不重复保存未经验证响应正文。

本地数据库仍串行保护同家庭候选生成；逐调用账本独立持久化已接入。每日预算预留、并发预算、Token最大额度、调用费用对账与通用Job租约/心跳尚未实现，不能用当前无付费调用来代替这些V1需求。真正模型、价格配置和质量按用户安排稍后接入；不得把Started自动清成免费。

验收：tests/builder_call_crash_acceptance.py实际终止两个隔离进程，分别验证返回但候选未提交和仅调用开始时的恢复；builder_retry_persistence_acceptance.py注入候选保存失败，确认每次真实调用仍在；builder_retry_api_acceptance.py核对包含账本的全家导出、真实加密恢复、删除不复活。标准接口回归验证分页和权限，实际页面检验本地不计费/Token不适用及人工审核发布。
