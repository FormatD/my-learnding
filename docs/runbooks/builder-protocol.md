# Builder 结构与来源校验

本地候选流程经过 `IBuilderCandidateProvider`、固定 `kc-candidate/1` JSON Schema及额外来源核对，再生成待人工处理的候选。当前唯一实际提供者仍为 Mock；外部来源许可检查和未配置模型拒绝继续生效。Mock保持“请审核者补充”的可测行为和边界，不能直接接受为正式能力；它的0分仅为模拟占位，1～12年级仅为模拟宽范围，不是对来源的年级或抽取质量判断。

固定协议要求名称、MATH学科、能力类型、1～12且有序的年级范围、可测行为、边界、合法UUID来源片段及成对真实引文、0～1模型分数。类型与正式目录允许值相同：Procedure、Concept、Application、Representation、Misconception。拒绝缺字段、多余字段、重复JSON字段、不合法数值或类型、Markdown包裹的非JSON响应。引文逐项对应片段Id，必须在本次实际输入片段中逐字存在；不接受其他来源、虚构定位、重复片段引用或不相等的引用/引文数组长度。结构合法不等于教材内容、测量行为或语义正确，仍须人工审核。

单次最多100片段、合计100000个.NET文本字符；响应最多1000000字符、100候选，每候选1～10来源。超过片段数不再静默截取前100项，也不输出部分候选。当前直接建库处理限30秒，总调用最多两次：首次结构/来源错误可将实际错误响应和校验编号提供给适配器修复一次；第二次仍错返回BUILDER_NEEDS_REPAIR。输入或响应超限不修复，超时返回BUILDER_TIMEOUT；原工作进程取消继续传播。接口要求实现方遵守取消令牌，受控等待本身不证明未来外部调用已物理停止或只计费一次。

新候选的ProtocolPayload保存校验后的完整原始结构，BuilderAttempt.ProtocolResult保存成功输出、实际调用次数及是否修复。原候选名称/行为/引文及人工决定仍按原流程保存，接受为草稿保持实际能力类型。页面显示成功结构核对和本地处理次数；失败或旧历史没有成功ProtocolResult时不推算首次成功、修复次数或模型质量。此次迁移只加两个可空文本字段，不补造历史输出。

该入口已有本地协议、结构/来源核对、一次修复上限与超时；逐次调用记录现已保存，真实模型Token/费用对账、每日预算预留、通用租约/心跳及付费提供者/预算的完整配置冻结仍未完成。当前Mock实际不调用付费模型，不能用这点替代这些设计要求。独立人工金标准、真实模型抽取/归并及质量指标按原V1范围保持开放。

验证入口：`tests/acceptance`的BuilderProtocolCases检查恶意结构/引文、超限、受控修复、取消与超时；`tests/openapi_acceptance.py`总是调用真实隔离服务专项，检查完整结构保存、重用、101片段失败和无部分候选。实际页面继续编辑测量题、人工发布、来源追溯及窄屏检查由`learning.spec.ts`的建库候选用例覆盖。

## 固定运行配置

新候选任务使用builder-input/3；创建时保存ModelConfigPayload及ModelConfigHash，包含builder-config/1、实际提供者/模型/提示版本、固定Schema摘要、输入/输出/片段上限、总超时和允许修复次数。InputHash包含原来源Hash、任务固定库Hash及配置摘要；同输入同配置复用结果，配置不同可创建独立任务。执行、人工重试及每次尝试的输入快照均读取原配置，不用当时环境覆盖。摘要不符、现代任务缺配置、未知字段/版本/结构或配置与运行型号矛盾拒绝；有配置但输入摘要不一致也拒绝。

本地可设置Builder:MaxFragments、MaxInputCharacters、MaxOutputCharacters、TimeoutMilliseconds、RepairAttempts（环境变量用Builder__前缀）。只影响以后创建的任务，最大分别100、100000、1000000、120000、1，均须正值，修复可设0；默认100/100000/1000000/30000/1。父级JSON固定协议与服务端硬上限仍生效，配置不能扩大硬上限。页面显示任务创建时上限，重新处理沿用同一组值。

builder-input/2且两个配置字段均NULL的旧记录保留明确兼容流程，采用当前可识别的本地协议默认保护，但不会补造创建时配置或称旧上限已被记录。若将所有现代版本标记与配置一起毁损成旧形态，NULL本身无法证明原事实；不会推断恢复未保存数据。新配置只覆盖当前Mock候选协议与资源限额；未来提供者价格、Token预算、并发/租约配置需要对应版本继续固定，不能宣称这些尚不存在的参数已冻结。

逐调用账本的保存、未知费用、进程中断与私有导出规则见[调用账本手册](builder-calls.md)。

## 逐项候选审核

在“辅助建库”点击某项“核对此候选”。GET /builder/candidates/{id}/review-context以一致读取展示原候选、运行/模型/提示版本、完整结构输出与实际引文片段；仅本家庭ContentEditor（含Publisher）可读，孩子403，另一家庭404。相近能力定义与支持题目来自创建时固定正式内容，不由后续发布替换；显示实际可测题目的总数、最多3道支持题及最多2道其他测量目标的对照题。前置/背景/零份额/NoEvidence不冒充测量支持，对照题不计作当前能力证据。支持题参考答案只提供给内容维护者。检索和原输出分数仍是模拟流程信息，不代表正式模型质量或正确概率。

家长可校正名称、可测行为和能力边界，必须填写1～4000字本次审核依据，再选择接受为新草稿、关联已有能力或拒绝；没有选择时保留Pending供稍后处理。依据由实际输入保存，不再填固定文案。接受不发布，须继续补充题目、整份内容审核及明确发布。原Candidate名称/行为/边界/ProtocolPayload保持，实际校正与选择留在审核审计/草稿，ReviewReason与追溯保存本次理由。关联仍需当前本家庭有可用正式发布的稳定能力，不能因历史相近排序自动关联或发布。

页面固定读取时的家庭版本提交决定。其他页面真实写入后旧版本412，当前校正和依据保留；“重新读取此候选”明确采用当前记录并清空未提交内容，须再次核对。不会利用其他查询取得的较新版本掩盖过期审核。已处理的候选不能重复决定，服务器409。来源和题面标签按文字渲染，不执行内嵌标签。

旧版本缺少完整结构输出时仅展示实际保留片段和检索结果，不补造年级或评分，不回填原NULL。现代builder-input/3或builder-input/4缺失结构输出422 CANDIDATE_PROTOCOL_UNKNOWN，结构及引文仍经过原协议门禁；无效引文422，不生成虚构片段。旧版本兼容与损坏现代数据专项使用明确受控数据库夹具，不冒充历史旧程序升级执行证明。

验收入口tests/builder_candidate_review_acceptance.py使用实际HTTP创建来源、正式内容、后台候选和后续发布，核对冻结定义/测量题、三种决定、空白/超长依据、真实另一页写入造成的412、原候选保持与权限；--browser验证明确理由、新建/拒绝、过期编辑保留、窄屏及标签按文字显示。该流程不替代正式教材人工审核、真实模型语义评测或实体平板试用。

## 固定候选检索

当前新任务采用builder-input/4、builder-config/2。ModelConfigPayload/Hash同时固定builder-retrieval/1、TopK、模拟空间、CandidateDefinition查询和ExactKCType类型规则。Builder:RetrievalTopK（环境变量Builder__RetrievalTopK）默认10，允许1～50；仅影响新请求，数量变化纳入输入摘要，不把原完成任务当成新的设置结果。新任务以原候选名称/可测行为/边界组成查询，只列相同KC.Type的正式能力，按实际模拟分数与稳定Id排序，没有同类型能力时返回空列表，不自动关联、新建或发布。页面显示原数量和方式。

现有数学候选协议仍只接受MATH。KC目录尚未提供独立学科/年级元数据，此处没有声称实现跨学科或跨年级的完整召回边界；真实Embedding、Alias/语义混合排序及K1固定评测仍待推进。模拟空间与方法不是模型质量证明。

builder-input/3与builder-config/1保留来源片段查询、不筛类型、最多10项的原兼容方式；旧未保存配置的builder-input/2也保持明确兼容，不补造创建时检索字段。新版本缺失检索/配置、空间或方式无法核对时在调用前拒绝，不替换为当前设置。旧配置JSON不增加retrieval:null，原描述/Hash和候选保持。运行处理和恢复读取保存的配置，运行环境后来改TopK不会改变原申请。

tests/builder_retrieval_acceptance.py在实际审核发布固定库夹具经真实后台验证两项同类型结果、旧方式及重复处理原字节、非法空间零调用/候选、家庭删除；tests/builder_retrieval_api_acceptance.py实际启动TopK=1的服务，预先冻结TopK=2的任务仍产生2项，旧任务保留原方式，新HTTP请求实际产生1项且摘要不同，重复请求复用。实际源和库通过受控审核/发布设置，不是正式人工教材验收。规则专项验证异类型高相似候选不混入、相同分数稳定排序、空库、边界数量和旧JSON保持。
