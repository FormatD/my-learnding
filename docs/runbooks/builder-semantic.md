# 候选语义归并建议

## 阶段范围

BuilderSemanticProtocol与LocalBuilderSemanticProvider补齐四类语义建议协议和本机传输。生产建库仍保存原NeedsReview及模拟召回；此提供者没有注册到生产，也未直接更新Candidate、Alias、草稿或审核决定。后续需要固定输入任务、独立调用/共享家庭预算、锁外等待及短结果事务核对，再将原建议交给人工审核。

## 固定输入与四类结果

逐候选捕获稳定CandidateId、可测行为/边界/学科/年级/类型、实际来源片段、冻结召回定义/修订、已审核Alias和最多3道实际测量支持题。完整候选抽取协议及原逐字引用先验证；召回定义的名称/行为/边界必须与冻结正式库一致。同已记录学科及同类型，跨年级允许关联。最多50项召回/24000字符，超限明确拒绝；不静默删项。默认召回K=10仍来自检索配置。

模型不接收原候选置信分数、相似排序分数或已有语义决定。支持题来自给定冻结库的真实测量映射，示例只是判断依据，不代表独立人工金标。只看名称、Alias或年级不能证明同一能力。

- LinkExisting：关联本候选至一个给定正式能力，必须同一目标Id/修订；不是合并两个正式能力。需要候选来源及所选能力定义的逐字引文。
- CreateDraft：建议形成独立待审能力，需候选原文依据；有限召回不能证明全库无重复。
- Reject：建议该候选不构成可测能力，说明理由；不是自动拒绝。
- NeedsReview：信息不足或边界冲突，明确交给人核对。

结果须保留中文理由和固定CandidateId。非关联决定必须为空目标/空定义引文；虚构来源/修订、改写引文、漏字段/未知字段/重复字段、概率和额外自动通过标志均拒绝。结构核对只证明身份和出处，不能证明归并语义或质量合格。任何建议都不能自动接受、发布或更改学生学习。
