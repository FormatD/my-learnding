# 辅助建库阶段与逐条数据

辅助建库页面上方的“每个阶段的任务与数据”提供阶段总数、完整分页列表和单条详情。任务列表默认20条，可逐页查看历史记录；每类关联数据也各自分页，不限于最近50条。列表随工作台刷新更新；展开详情保留读取时的记录，可手动刷新。历史失败、模拟与手工维护不会隐藏或计作真实模型成果。

| 阶段 | 列表依据 | 可查数据 |
| --- | --- | --- |
| 来源与分段 | 实际 Source | 保存文字、使用范围、摘要、片段、对应解析和生成运行 |
| PDF 解析 | ParsePDF BuilderRun | 当前保存来源、片段、每次处理尝试、后台任务和领取、中断/恢复依据 |
| 候选生成与召回 | Candidates BuilderRun | 原配置、正式库、实际保存候选及召回、调用用量、预算结束核对、后台领取 |
| 向量索引 | ModelEmbeddingIndex | 完整固定库、配置/空间、向量、摘要；目前实际模型未注册生产 |
| 语义建议 | BuilderSemanticPreparation | 原固定快照、候选、原建议、每次调用、原模型返回/完整性、结束核对、后台领取 |
| 候选人工审核 | Candidate | 候选原结构/召回/人工决定、生成运行、来源片段、正式能力定义及题、语义准备、审核别名和草稿 |
| 内容草稿 | ContentDraft | 保存内容、形成草稿的候选、整份审核、对应映射准备及建议批次 |
| 映射准备 | MappingPreparation | 固定输入快照、实际调用/用量、结束核对、成功保存的建议运行、后台领取 |
| 映射建议与审核 | MappingRun | 原固定来源、正式库、每项建议、人工校正/决定及原准备 |
| 正式发布 | Release | 实际发布内容、撤回标记、整份审核依据和稳定身份/修订引用 |

各阶段均可查允许的内容操作类型中、StudentId 为空且按此记录编号关联的实际操作审计及恢复依据，不通过关联正式版本编号展示学习/学生审计，逐页读取。编号关联基于原审计文字中的记录编号；没有该编号的旧审计不会推定归属。同步来源导入、候选审核、草稿和发布展示真实工作记录，不补造后台任务或领取历史。阶段总数表示保存记录数，不是教材覆盖率或完成百分比。草稿列表包含整个家庭内容草稿，不推定每份来自教材模型。

点击“查看任务数据”展开原记录，再打开相关数据行。常用字段使用中文标题；嵌套对象和原保存 JSON 文字可展开，长数组每20项展示。未知值显示“未记录”，不会把未知用量补成零。文字以纯文本显示，教材或模型返回中的 HTML/脚本不会执行。查看、刷新、展开和翻页均为只读，不触发模型，不改写候选或人工审核表单，也不审核/发布内容。

当前保存来源和候选审核状态与创建时固定快照分别标注。创建时能力库仍可查看其实际撤回标记，不替换成最新版本。旧候选生成和映射物理调用未保存原返回字节的，仅展示实际保留的候选/原结构建议和摘要，不从摘要补造原响应。

后端阶段总览、列表和详情均要求 ContentEditor，限定本人家庭。每次响应在同一只读一致快照内核对总数、页数据及关联记录；任务编号放在错误阶段或另一个家庭会404，孩子会403。非法阶段、页数、页大小或相关数据名会明确拒绝。每次读取最多20条相关行；分页保留稳定创建时间/编号顺序。任务详情不是自动审核入口。

阶段接口为 GET /builder/stages、GET /builder/stages/{stage}/tasks、GET /builder/stages/{stage}/tasks/{id}。接口契约保存在 docs/api/openapi.json；相关数据通过 related/relatedPage 独立翻页。

验证：tests/builder_stages_api_acceptance.py 使用实际隔离服务、临时PG、真实Mock队列、审核/发布流程夹具，检查10阶段、23来源和41片段完整翻页、调用/领取关联、读取不改写、非法参数及家庭/孩子门禁。tests/builder_semantic_api_acceptance.py 进一步验证实际受控HTTP语义返回及建议关联，不计真实模型质量。tests/builder_stages_web_acceptance.py 使用已安装浏览器核对阶段及既有候选语义页面；测试夹具不代表教材准确率或实体平板验收。
