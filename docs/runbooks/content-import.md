# 本地题包导入与审核

在“内容与发布”的“导入本地题包”选择JSON文件。文件最大2 MB，格式为已有DraftInput的title和catalog；catalog包含kcs、questions、resources、lessons、relations五个数组，可带教材、单元、课程和教学覆盖。导入先显示数量，不自动调用模型或保存。文件读取只检查结构，不能代替教材适配、数学答案、能力归因、变式组及许可审核。

明确点击“保存为待审核草稿”会通过原/content/drafts创建独立Draft，然后打开既有编辑器。已有编辑未保存时不能再导入；权限、版本与来源核对仍由原服务端控制。保存响应失败保留预览和原命令/版本，原命令重试避免已提交但响应丢失时重复建立草稿；取消或重新选择文件另开导入。导入不审核、发布或绑定学生，不修改既有草稿和正式版本。

## 两页除法原创补充

运行python3 scripts/prepare_division_pack.py，在私有.local/textbook-workflow/division-original-draft生成content-pack.json、manifest.json和review.md。20道题、4份原创纸笔资源、3个拟议能力、2个课时，仅对应北师大版二年级下册除法两页情境，不是整单元内容，不替代原三年级混合运算目标。具体印次与所有人类审核均Pending。

8道竖式题采用ObservedSteps，分别观察求商和余数检查；没有观察的步骤保持Unknown。另12道最多/至少题直接给出商和余数，只测余数处理，不把列式计算或阅读速度视作同一能力证据；包括整除对照。答案关系通过a=bq+r及上下界、容量最小性和完整份最大性核对。数学关系校验不替代文字、难度、实际步骤及教学可执行性审核。只有Basic、7个变式组，没有迁移或延迟保持验收，不能把20题当作20个独立模板。

当前家庭已通过真实页面导入该草稿，随后为两课时分别选择书内第13/11页的整页转写来源并保存为第2版Draft；这不是接受模型候选，原9项本机候选仍待审核。学生仍绑定原三年级内容，未发布此二年级补充。应对照原页、review.md、实际题面和能力边界逐项复核，再使用原审核发布流程。
