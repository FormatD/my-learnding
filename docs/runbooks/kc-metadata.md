# 能力的独立元数据（2026-10-05）

能力定义KC现在可保存Subject、GradeMin、GradeMax，随定义修订保存在ContentRevision.Definition、草稿、正式内容快照、固定任务库及私有导出中。它们不属于某本教材；不根据编码、教材标题、教材年级或别名推定。

| 字段 | 已记录定义的要求 |
|---|---|
| Subject | MATH、ENGLISH、CHINESE、SCIENCE、OTHER |
| GradeMin / GradeMax | 同时为1～12的整数，起始不能大于结束 |

三字段全缺失/NULL是明确的旧未知形态；序列化时不增加三个NULL键，保持原定义JSON和旧输入摘要。任何部分记录、未知学科或非法范围都不能通过正式内容校验。旧完整定义仍保留兼容，不补造缺失信息。

内容编辑器可明确填学科与适用范围，补充或调整后创建新修订，再人工审核、预览和发布。已记录正式学科不能更换或清空：服务器检查此稳定能力全部已记录修订，即便最早修订未知，也不能借后续修订改变学科。要改变学科应建立独立能力；旧证据不迁移。年级调整不改变Code或原数学测量签名，但改变定义修订；原正式快照和已领取学习引用不替换，也不复制掌握证据。

新候选接受为草稿前核对完整原结构与引文，并把原输出Subject/GradeMin/GradeMax带入新定义；名称、行为和边界仍由家长校正。原候选/协议不改。缺失旧协议时保持未知，现代缺失/损坏输出明确拒绝。Mock的1～12范围仅为流程占位，编辑器保留它供人核对，不冒充已判断来源年级；正式使用需人工调整和审核。

## 新请求的检索边界

当前新配置为builder-retrieval/4，仍通过builder-config/2、builder-input/4和原输入摘要固定：

- SubjectPolicy=ExactRecordedSubject：在排序与别名优先之前，只保留与候选已记录学科相同的正式KC，未知学科不进入新匹配列表。
- GradePolicy=NoGradeExclusion：不按年级排除同学科同类型能力，避免漏掉跨年级同一能力；没有新增年级排名分数。
- 原ExactKCType、TopK、空间、冻结审核别名、Unicode关键词/BM25及RRF策略保持。别名不能绕过学科边界。

UI显示固定策略、原正式定义学科与范围，未知时显示未记录，并说明如何通过新修订补充后重新准备任务。尚无同学科结果时保持空列表，不自动创建、关联或发布。关联接口也拒绝已记录的其他学科；当前retrieval/4还要求目标同学科同类型，不能用伪造目标请求绕过。

旧retrieval/1、/2、/3按保存的原策略执行，不加subjectPolicy/gradePolicy字段或更换配置摘要；旧/3仍可返回原学科未知的库，不能把它解释成已确认同学科。后增、后改或后发布正式库不替换已排队任务的原库与范围。

当前候选抽取协议仍只允许MATH，其他Subject值是可人工维护的能力定义元数据，不是其他学科抽取已接入的证明。真实Embedding、语义判断、候选协议提取Domain及固定人工质量评测继续开放。

## 固定原创题包

原创V1题包的稳定KC修订已有保存参考，不能因共享示例新增字段而在同一RevisionId下改内容。生成器明确保留该题包原三个未知字段；原九个能力定义与保存参考的规范化JSON摘要一致。需填学科年级时通过内容编辑器新修订和人工审核，不改固定旧修订。新生成的20题流程示例和乘法样例由代码作者明确声明数学/三年级，这不代表正式教材印次已核对。

## 领域、能力复杂度与认知描述

KC定义修订增加可空 Domain、DifficultyLevel、CognitiveLevel，旧定义未知时不输出NULL键、不从题目/教材/编码反推，固定原创题包原修订保持不变。这些字段随原完整定义保存、审核、发布、冻结候选参考及导出，没有新表或回填。

Domain 为1～200字的单行人工领域说明；CognitiveLevel 为1～100字的单行人工认知层级说明，不强制推断或自动转换成某一教育学分类。两者禁止空白、控制字符和首尾空白；编辑器去掉首尾空白，清空表示未记录。DifficultyLevel 使用 Easy/Medium/Hard，页面显示简单/中等/较复杂；非法值审核拒绝。这个字段描述能力复杂度，与每道题自己的Difficulty分开，完全不参加判分权重或掌握公式。

已有能力可通过新修订调整这些描述，原Code/身份与数学测量签名不变，不复制证据。直接使用旧RevisionId修改任一描述仍拒绝REVISION_IMMUTABLE。修改可测行为、边界、类型或RequiredCoverage继续要求独立能力，不能用描述字段绕过。

内容编辑器、已发布能力定义与候选固定参考均可读这些描述，未记录明确显示未知。检索仍按保存的retrieval/4同已记录学科和同类型，不按Domain、能力复杂度或认知描述排除；不引入新的排名或更换已排队任务的配置摘要。候选抽取协议当前没有这三个输出字段，新草稿保持未知，须人工核对后填写，不声称模型已提取。
