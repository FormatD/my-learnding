# 本地运行与恢复

## 使用与配置

`scripts/dev.sh` 以单站点方式提供家长与孩子入口。数据目录 `.local/postgres`，应用日志 `.local/api.log`，这些目录不得同步公开。

本机数据库使用 loopback 与本地开发信任认证。不能直接暴露到网络。远程部署要建立独立应用用户、密码或证书认证、HTTPS，并关闭数据库管理端口。家庭私有文件现存于数据库 bytea，完整备份包含这些文件，避免数据库与文件备份不同步。

## 备份

将 PostgreSQL 工具加入 PATH。配置 PGHOST、PGPORT、PGUSER、PGDATABASE 与 BACKUP_PASSPHRASE，执行 `sh scripts/backup.sh`。脚本先成功完成 custom-format 数据库备份，再用 GPG AES256 加密；不会将口令写入命令行。备份默认保留 `.local/backups`，正式运行应配置每日计划任务、30 天保留和独立磁盘。

RPO 24 小时与 RTO 4 小时仍需正式运行和定时备份演练确认；开发期间手工备份不等于已经满足持续服务指标。

### 到期执行、保留与失败恢复

`scripts/daily_backup.py --config <私有配置绝对路径>` 执行一次到期检查；加 `--watch` 后独立进程每分钟检查，距上次快照开始23小时执行新备份，给24小时目标留缓冲。当前开发机配置在 `.local/daily-backup-config.json`，私有口令在 `.local/daily-backup-key`，归档在 `.local/daily-backups`；调度日志在 `.local/daily-backup.log`。所有这些本机私有文件不入版本库。

配置包含绝对路径 `backupDir`、`stateFile`、`passphraseFile`、`dataDir`、`deletionLedger`、`familyDeletionLedger`，以及 `postgres` 的 `host`、`port`、`user`、`database`。仅支持本机数据库；文件与归档目录须由当前用户持有且不开放组/其他人权限，不接受符号链接口令。默认23小时间隔、30天保留、整次工具执行总计最多900秒。需将 `pg_dump`、`pg_restore`、`psql`、`gpg`、`gpgconf` 加入PATH。口令不能丢失或直接覆盖；旧口令需保留至对应备份过期。

调度的运行锁为进程持有的文件锁，进程终止会自动释放。成功归档先AES256加密，再解密逐字节核对、检查归档可列出全部数据库表，最后原子公布归档、摘要清单及状态。检查可解密并不是实际恢复演练；状态 `archiveVerified` 和 `restoreVerified` 分开记录，当前本机快照后者仍为false。临时明文在私有临时目录，正常完成及可处理异常会清除；系统强制终止可能遗留临时目录，应确认对应进程已停止再处理，不能把此情况描述为没有遗留。

超过30天的清理只针对本工具命名、带有效清单、时间对应且摘要一致的自有归档；近期、未知、缺少清单、摘要不一致或符号链接均不自动删除。仅在新备份检查成功后清理。失败保留上次成功记录和旧备份，默认等待五分钟再试；已修复故障后可用 `--force` 请求立即重新执行，不能与 `--watch` 同时使用。归档缺失或配置更换会重新执行，不把旧位置的成功状态当作新位置已经备份。

当前调度已由macOS当前用户的登录服务管理，登录时启动，进程退出后系统重新拉起；不是登录前运行，实际整机重启尚未测试，电脑关机/睡眠期间无法执行。状态和心跳文件本身不证明进程活跃，需结合实际进程检查。负责人状态页已核对归档摘要、最近成功时间及实际调度进程，恢复演练和物理独立性仍为待验。当前归档与数据同机同盘；即使两个目录属于不同APFS文件系统也不能推断物理磁盘独立。`requireIndependentDisk=true` 在物理独立性未验证时拒绝运行，不以目录名放行。

正式运行须确定独立磁盘、独立保留最新删除清单和恢复口令、实测整机重启及用户登录启动，并在该环境验证持续RPO与恢复RTO。隔离验证命令为 `python3 tests/daily_backup_acceptance.py`，先按README构建 `tests/persistence`。它包含真实新空库恢复与逐行核对、私有附件及最新删除清单保护，但不代表本机全量数据已完成恢复演练。

### macOS登录启动及系统重启调度进程

先用 `python3 scripts/install_backup_agent.py --config <私有配置路径>` 生成 `.local/launchagents` 中的项目专属plist，检查后加 `--install` 安装。安装器使用当前Python、脚本和配置绝对路径及固定工具目录，不将口令或连接信息放进plist。每个项目路径对应独立服务名，只有既有文件和实际系统服务都属于该项目才更新；无关目标拒绝覆盖。更新时拿备份运行锁，已有备份进行中返回 `BACKUP_RUNNING_RETRY_LATER`，不可为更新强行中断备份。

本机已安装 `local.learning.backup.ff5dcd2f8fa8` 到当前用户 `~/Library/LaunchAgents`，`RunAtLoad` 与 `KeepAlive` 生效；日志在 `.local/daily-backup-agent.log`，私有权限600。系统GUI域的实际PID已与完整命令及心跳核对，手动调度已停止，不重复运行两个调度。临时服务测试实际终止进程后看到新PID且到期前不产生重复归档；这不是整机重启试验。

启动依赖本地数据库可用。登录后数据库尚未启动时，备份会失败并按既有退避继续检查，应用运行状态可提示；不能从备份登录项推定数据库和应用本身也已自启动。启动路径移动、Python或工具安装位置改变时需要重新检查配置。要停用时先确认无备份执行，再卸载该项目服务并移除对应plist；不要卸载其他用户启动项。恢复口令、最新删除清单与旧归档仍需保留。

隔离生命周期验证：`python3 tests/backup_agent_acceptance.py`。使用唯一临时系统标签和一次性数据库，完成载入、真实备份、持锁更新拒绝、真实进程终止与自动拉起，并卸载临时服务。实际用户注销/登录或整机重启、连续RPO及独立磁盘仍需在正式环境验证。

### 负责人备份状态及告警

服务通过 `BackupConfigFile` 指定私有备份配置；使用 `scripts/dev.sh` 且本机私有配置存在时会自动启用状态读取。未指定则显示待配置；配置数据库必须与当前服务连接匹配，避免把其他测试库的备份当作本库保护。家长页面只向家庭负责人显示这组本机状态，普通家长无该信息，孩子不能访问运行状态接口。配置路径、口令路径、归档目录及进程命令不进入响应。

状态读取核对密文归档长度与SHA256，结合心跳时间、实际PID对应的完整运行命令确认调度活跃。调度需用脚本和配置绝对路径运行 `--watch`；相对命令或不匹配的PID不能单靠心跳认定活跃。最近失败保留最后成功快照；超过24小时、归档缺失/摘要不一致、调度停止及状态不可读分别提示。畸形时间或不匹配配置显示无法核对，不能视为健康。

### 全量快照临时库恢复演练

运行 `python3 scripts/restore_drill.py --config <私有配置路径>`，不切换或改写当前应用数据库。工具先核对最近成功密文摘要，解密提取归档COPY原始字段作为预期数据；恢复到唯一 `learning_restore_drill_` 临时空库，按现有恢复脚本清除登录/响应缓存并应用最新家庭及学生删除清单。所有数据库约束必须已验证。

预期保留范围从归档记录、最新删除清单及实际数据库外键删除规则计算；另行处理学生图片共享引用和来源引用。逐表按归档列顺序比对全部行的COPY字段多重集，包括字节字段，任何缺行、多行或字段差异都拒绝通过。对换行、制表、反斜杠及Unicode NEL作了独立隔离验证。结束前确认删除清单没有变化；如变化需重新演练，不将旧清单结果当作最新保护。临时库与可处理异常产生的明文临时文件在结束时删除；强制终止的现场需确认进程已停止后检查。

私有记录为 `stateFile` 同目录同名的 `.restore-drill.json`。负责人页面仅在归档名、密文摘要、快照开始时间、表数和完整核对结果对应当前快照时显示“临时库恢复：已验证”及时间/用时。新快照未演练、记录错配或畸形时显示待演练，不抹去独立核对过的归档状态。记录不包含原始行、口令和实际恢复库凭据。

2026-10-03（上海时间）本机新建含映射运行、原始建议、人工决定和固定映射修订的加密快照恢复到临时空库：51表、33,989条应保留记录逐列一致，演练3.23秒；最新删除清单已应用，临时库已清理。该用时包括解密、还原、删除保护与核对，但没有灾难后的人工准备、独立磁盘取回、应用切换和完整用户使用验证，不能作为正式4小时RTO达标。持续24小时RPO和独立物理磁盘仍未验收。

独立监控每5秒记录首次告警及解除，不重复刷相同告警。负责人界面每10秒检查；成功归档、实际恢复、独立物理磁盘是分开的结果。可解密、原文件摘要一致或进程活跃不证明持续RPO/RTO已经达标；完整备份验收标记仍为false。

## 恢复

停止应用。创建新的空数据库，设置 PGDATABASE 指向新库，配置 BACKUP_PASSPHRASE、DELETION_LEDGER 和 FAMILY_DELETION_LEDGER，执行 `sh scripts/restore.sh <加密备份文件>`。脚本不清空既有数据库；遇到已有 schema 报错停止，避免误覆盖。

独立删除清单通常在 `.local/deleted-students.txt`。没有删除时创建空清单。必须独立于数据库备份保留，恢复后按家庭和学生 UUID 重新删除，撤销相应孩子会话。恢复旧备份不能复活已删除学生。家庭删除清单通常在同目录 `deleted-families.txt`，可用 FAMILY_DELETION_LEDGER 指定路径；必须独立保留，即使为空也不可省略。恢复先清除会话与缓存，再按家庭清单清除整家数据，随后处理学生清单。任一清单缺失时拒绝恢复。

恢复会清除登录会话与传输层响应缓存，所有家长重新登录；作答 ClientSubmissionId 与领域记录保留，不能重复制造证据。启动前检查活动内容、计划、作答、活动评估世代、复习日程和私有图片。针对一个学生调用家长重建命令，确认固定输入重算一致。首次演练及结果记录于 STATUS.md。

## 内容纠错

已发布内容不能改写原修订。创建新草稿，修改题干/答案/映射，审核后发布新版本，绑定学生。旧学习会话继续读取领取时的 ReleaseId。活动版本切换不会自动重新判分旧答案。

判分更正：家长区预览前后结果及重放范围 → 确认 → 等待后台追平 → 查看新世代证据。映射历史更正：先发布保留原题稳定身份、题干/答案/难度的映射修订，在证据页选择首次作答与更正版本，预览后确认。后台保留原始领取版本，使用指定映射建立新世代，不直接编辑数据库。

## 故障

API 错误带 traceId，可在私有应用日志定位。模型不可用时继续使用已发布人工内容。后台 Pending 超过 30 秒先查看日志和数据库连接；不要重发不同作答标识来“加快处理”。

停止服务不会删除源数据。重新启动会继续消费未处理 Outbox。事务失败不会切换半成品掌握/复习投影。

隐私删除通过家长密码与明确文本双重确认。删除级联清理学生学习关系、图片与响应缓存；保留不含学习内容的独立删除标识。家庭内容库并非学生专有，学生删除不会删除其他学生仍可使用的正式内容。

## 学校进度纠正

进度与计划页选择要纠正的记录及正确课时，填写原因后更正；也可明确撤回。原记录标为 Superseded/Withdrawn，变更保留操作者、原因和前后快照。重新确认会追加变更历史。规划只采用 Confirmed 记录，家长需重新生成并确认草稿才改变执行安排，旧作答和已发布计划保留。学生导出包含全部进度记录与 progressChanges。迁移前的进度保留为 Confirmed；缺少旧发布关联时不猜测版本，ReleaseId 保持空。

## 人工内容编辑

内容与发布页可新建空白草稿或编辑建库草稿，增加能力定义、测量题、纸笔/HTTPS讲解资源、课时及前置关系。未完成草稿可保存；正式审核要求每个能力有正份额的测量题、明确答案和讲解，步骤测量使用家长观察题型。编辑未保存时不开放审核发布，避免发布旧清单。

已发布能力的行为、边界和类型在页面只读。名称修订可以沿用原身份；改变测量行为、边界、类型或覆盖要求需要新增独立能力，服务端阻止旧身份改义。前置关系有环会返回能力名称路径。新增能力不会继承旧概率，须按自身作答建立证据。

## 家庭负责人及全家数据

家庭设置页由负责人管理成员。家长权限可访问学生记录，内容编辑只准备内容；发布审核包含编辑及发布权限。负责人必须保留家长权限。空权限停用成员，相关成员及孩子须重新登录。旧库迁移保留账号角色；仅原来单账号且具备家长权限的家庭补齐负责人，多账号家庭不推断归属。

负责人可下载全家 ZIP：manifest.json 包含业务表、成员元数据及附件目录；files/ 包含原始私有附件，不含密码、登录令牌或响应缓存。这是可阅读的业务导出，数据库恢复使用加密备份。临时 ZIP 位于私有 `.local/exports`，下载完成清除，崩溃遗留包最多由 15 分钟到期清理策略处理；用户自行保存的导出包不由服务器删除。

全家删除需要最新范围预览、负责人密码及“永久删除家庭”。成功后重新加载到登录页，展示并可下载删除回执。删除清单只含家庭 UUID 和回执 UUID，先记录已验证的删除意图，再提交数据库删除；如数据库事务失败，页面不报告完成，该独立意图仍在恢复时强制执行。不要丢弃或手工清空清单，否则旧备份可能复活数据。

## 教材与课程范围

内容草稿编辑器可添加教材、单元、课程及课时归属。教材版本说明填写实际信息，样例的“具体印次待核对”不能视为正式教材审核。来源从已导入的家庭来源中选择；不能引用其他家庭来源。教材和课程是导航与任务来源，能力身份独立。课时归属改变通过新的内容修订发布，旧发布与历史作答不改写。

进度页按教材单元/课程分组课时。能力练习目标可选择整个单元或课程，也可进一步选择其中一个能力；没有正式测量题时显示内容缺口。课程听力和阅读仅安排活动，不增加掌握证据。切换目标范围会形成新修订，旧任务保留生成时的范围，旧完成次数不会抵扣新范围。未记录的旧目录保持未知。

证据页在有待处理结果时短暂自动刷新，超过 30 秒仍未完成可手动刷新并检查后台。浏览器全量验收会为认证限流自动错开登录窗口，接口验收仍建议顺序运行。

## 到期复习跳过后的安排

跳过或只看解析后放弃不会算作通过，也不会推迟复习到期日。家长当天重新生成计划可安排一个新任务，旧跳过记录仍保留；也可留到次日再安排。进行中、已完成、锁定和必做任务在重生成时继续保留，超出预算时须明确确认。

## 人工能力变更

在新草稿使用新的能力身份、测量题和映射，移除被替代能力及其引用，人工审核发布。进入“内容与发布”的“能力变更提案”，选择来源和生效正式版本，填写拆分/合并/替换理由。草稿修改留历史快照；提交后不可再编辑，审核人填写通过或拒绝依据。通过后预览范围并输入“记录能力变更”确认。

确认只记录关系并停用来源身份，不搬移学习结果、不重算旧概率、不改变既有复习日程或进行中任务，也不自动绑定新内容。家长单独选择学生的内容版本；新能力需要自己的诊断证据。旧发布版本和任务仍可追溯，新发布不能再次加入停用身份。权重可以留空，仅记录关系。拒绝的提案保持原文；重新提出时创建新的提案。

## 运行状态与结果积压

家长“家庭设置”中的“后台运行状态”显示本家庭待处理结果、服务异常计数和有权限的建库统计；负责人另外查看本地容量。超过30秒的结果更新会提示；自动重试达到3次停止后，可确认连接正常再“重新处理原始结果”。不能用新作答标识重复提交来替代故障处理。已处理结果不再重试；恢复后原告警自动解除。

独立监控每5秒检查并在 `.local/api.log` 记录 `Operational alert` 和 `Operational alert resolved`；数量不变的持续问题不重复刷日志。监控连接失败记录 `Operational monitoring unavailable`，不是健康。当前停止的建库失败会持续提示，恢复成功后解除，历史尝试仍在辅助建库保留；运行结果不影响既有正式内容学习。请求计数按家庭和分钟窗口存在内存，重启后清空，不用作长期运行报告。备份状态当前仍是待配置，必须单独完成每日加密备份、独立磁盘、保留和恢复验收。

## 建库持续失败
