# 本机模型映射接入

## 当前阶段

已实现 `mapping-model/1` 严格协议、本机传输适配器和独立诊断入口。当前网页的映射准备仍为 Mock/Manual；本阶段尚未将 LocalOmlx 接入 MappingPreparation 的生产执行或人工批量审核页面；独立持久调用、共用预算及只读/核对接口基础已补齐，不能把诊断结果当作家庭已保存的映射建议。

输入捕获 Question/Lesson/Resource 的稳定身份、对象修订、可用文字、明确的观察点，以及冻结能力定义和修订。题目含题面、答案、讲解和提示；课时目前只有标题；资源只含标题与纸本说明，尚不读取附件或外部网址。输入不含原 KC 关联、映射角色、份额或题目归因策略，避免照抄旧建议；分步观察点来自明确作者标注，不代表独立人工金标准。8对象/100能力/24000输入字符为明确拒绝边界，不静默裁剪。

每个对象恰好输出一次 Propose 或 NeedsReview。Propose 必须含逐字内容引用，能力身份和修订来自所给库，sourceRefs 指向冻结对象；未知、漏项、重复、改写引文、虚构观察点、错误证据方式/份额、超过六位小数或编造置信度均拒绝。NeedsReview 的 NoEvidence/空条目仅表示没有形成建议，不证明没有关联。资源与课时只表示教学覆盖，不能产生作答证据。结构通过不能证明数学、Primary或覆盖权重准确，全部结果仍待人类审核。

传输仅限127.0.0.1的HTTP /v1，禁止重定向与代理，固定模型、提示摘要、输出上限及总调用期限。初始、教学覆盖补充、全局引用约束以及当前按对象约束的提示/请求结构摘要均保留并可复现。当前输出结构按每个对象固定身份、修订和完整来源引用，并将课时/资源策略固定为NoEvidence、None和零证据份额。未返回/超时不补造用量，截断的真实输出与用量先返回，再由诊断拒绝候选；认证文件须本人可读写。当前传输返回事实，MappingModelCallTracking 可独立提交调用尝试，保存冻结输入/配置和真实返回用量，并与 Builder 共用预算锁/并发名额；生产后台尚未启用该包装器，不应直接用适配器替代生产队列。

## 验证入口

构建 `tests/persistence` 后运行 `python3 tests/mapping_model_protocol_acceptance.py`。使用受控本机HTTP返回，覆盖协议、原提示复现、截断真实用量、缺失用量、固定模型、超时、非私密认证及外部地址拒绝，不调用真实模型、不打开测试数据库。

真实模型诊断需明确设置 `OMLX_MAPPING_SMOKE=1`，运行 `python3 tests/mapping_model_local_acceptance.py`。默认读取私有 `.local/omlx.json`、`.local/omlx-api-key.txt` 和原创除法待审题包；可显式指定 MAPPING_LOCAL_CONFIG/PACK/KEY。程序只选一题、一课时、一资源，以草稿能力库进行隔离诊断，不冒充已发布正式库。原子保存 Started，再保存真实 Returned 或 NoConfirmedResponse；认证内容不进入报告。私有报告在 `.local/textbook-workflow/mapping-model-diagnostics/`，文件600，不提交Git，也不写家庭业务数据。

## 已补齐的调用记录基础

新增MappingModelCall和MappingCallReconciliation两张家庭私有表（72表/49迁移）。调用记录关联真实MappingPreparation，同家庭复合外键约束，独立提交Started、Returned、Failed、Cancelled或Denied，保存执行身份、重试轮次、调用序号、原内容/配置负载及摘要、实际用量/输出摘要或未知空值。开始前核对所领取任务、快照和捕获的对象/库输入，租约围栏与共用预算锁保护开始记录；模型等待不持有家庭写锁。结果事务失败不会删除调用记录。记录反映提供者调用尝试与实际返回；Started本身不证明网络请求已被模型服务接收。

建库与映射共用原BuilderBudgetPolicy。另一类调用处于运行或未知状态时，同一家庭不能绕过MaxConcurrentCalls；映射仅允许本机免费传输，无外部计费接口。未知调用不能因应用退出、取消或租约过期自动释放。家庭负责人须根据实际本机提供者/进程结束情况明确追加核对，原调用的未知费用/Token、失败和领取历史不改写；核对不能修改已知Token。后台执行停止确认不等于本机模型服务已经结束。

`GET /builder/mapping-calls`支持家庭私有分页及preparationId筛选；`POST /builder/mapping-calls/{id}:reconcile`追加本机结束核对。孩子拒绝403，其他家庭不可读取或核对，普通内容成员不能代替负责人核对。完整家庭导出包含新记录，家庭删除通过真实级联清理两份账本及核对。网页账本与真实映射执行入口仍待接入，当前家庭没有这些映射调用。

`tests/mapping_call_ledger_acceptance.py`用真实PG和受控提供者验证两向并发、等待期间同家庭写入、返回记录与结果回滚隔离、未知保留、原记录不改写及级联删除。`tests/mapping_call_crash_acceptance.py`实际SIGKILL提供者进程，等待真实租约过期，证明开始记录保留未知且替代调用被拒绝；在明确记录观察到的停止后才允许新的独立调用。API专项使用明确标注的合成行核对分页、权限、核对和导出，不把合成行计为真实模型结果或质量依据。

## 后续完整接入

LocalOmlx下一步需要新版本冻结任务快照，将已实现的独立调用包装器接入实际队列，并保存结构验证结果；不能伪造 BuilderRun 来借用现有 BuilderCall 外键。模型等待必须在家庭锁外，短结果事务重新核对租约、请求人内容权限及未撤回的冻结库，保留已有取消和重试历史。家庭并发/未知调用额度需与 Builder 共用真实限制。随后接入待审核建议和批量审核，接受仅生成新草稿，不自动发布；旧Mock/Manual快照和兼容入口保持原语义。独立人工质量集及教材正式审核仍是V1门槛。
