# 本机模型向量与检索

## 当前范围

ModelEmbeddings、ModelEmbeddingSpace及LocalEmbeddingProvider是E10真实向量检索的基础实现。当前生产建库仍使用原模拟向量及冻结builder-retrieval/4；没有把新提供者注册到生产，不能把此阶段计作真实语义检索或四类归并判断完成。

本机`GET /v1/models`已读取成功，列出当前Qwen/Gemma及MarkItDown，但响应不提供向量能力元数据，尚未确认可用向量模型。没有下载新模型或把聊天模型替作向量模型。接口依据[oMLX官方Embedding请求/响应定义](https://github.com/jundot/omlx/blob/main/omlx/api/embedding_models.py)：POST /v1/embeddings、float返回及按index对应输入；明确truncation=false，不请求降维。实际返回维度必须等于固定配置，否则拒绝整批。

## 固定身份与完整返回

空间身份包含Provider、Model、明确ModelVersion、Dimensions、PreprocessingVersion，摘要使用完整结构，不能只按模型名称比较。当前仅支持LocalOmlx与NFKC/trim/小写固定处理；模型固定版本需在后续配置/索引任务中关联实际模型工件，HTTP响应的模型名本身不能证明权重版本。认证路径与密钥不进入空间身份。

单批最多64对象/24000处理后字符；KC与Candidate分别保存实体修订、原实际发送文本摘要、空间及维度。按服务返回index重排，不依赖返回顺序；缺失、重复、越界、错误模型、base64、错误维度、重复字段、空/零/非有限向量拒绝整批，不静默补向量。以最大坐标缩放后归一化，避免有限大值平方溢出。相似度需明确预期空间，连同空间声明被篡改的维度也拒绝；旧mock空间不能混入。

小规模内存召回验证完整冻结库及每个向量修订/实际文本摘要，不能拿部分索引假装完整。同已记录学科、同能力类型筛选，不按年级排除；实际余弦排序与原关键词BM25/RRF、人工Alias融合。分数只是排序依据，不能自动接受或当成概率。原Mock算法、快照与旧维度规则不变。

## 本机传输和用量

固定127.0.0.1 HTTP /v1端点、模型、维度空间、总等待期限。禁用重定向和代理，认证文件须仅本人可读写；输出限制16MB。返回原响应与实际prompt_tokens，缺失/异常用量保持未知，output_tokens不补零。结构或向量校验在传输之后执行，原返回用量不会因向量拒绝而被抹掉。

当前传输尚无生产持久调用包装器，不能直接从正式建库使用。下一阶段须补齐持久调用、建库/映射共用家庭预算、固定索引输入/配置、锁外等待和短结果事务重核对；未知调用不能因取消/重试而释放。模型升级使用独立新空间重新建索引，不能改写旧向量来冒充同一空间。

## 验证

构建tests/persistence后运行`python3 tests/model_embedding_acceptance.py`。程序只用真实受控本机HTTP，测试不访问实际模型或数据库，不代表语义质量评测。覆盖固定模型/float/禁止截断、原用量保留与未知值、权限/认证/超时，以及完整对象索引、空间版本/维度隔离、无效数值和跨年级召回。已纳入scripts/ci_check.sh。
