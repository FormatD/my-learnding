# 家长投入记录

在“每周回顾”里填写实际投入的日期、类别和分钟数。日常确认作业、调整计划选“日常确认与调整”；集中建库、审核题目和资源选“集中建库与内容审核”。它们分开汇总，不用内容准备耗时冒充日常维护成本。

这是家长填写的记录（ParentReported），不是浏览器计时，也不证明连续使用。记录真实投入，扣除休息或做别的事情的时间；不能从页面打开时间推算。分钟范围0.1～240，最多一位小数，可补记今天及此前27天。日期采用学生时区。没有填写的日期保留数据缺口，不能当作零分钟或低负担。

默认周汇总计算今天及此前6天的有效记录，可在“周报结束日期”选择往周，或使用前一周/后一周。所选一周采用该结束日期及此前6天；列表仍显示最近28天，列表范围与所选周的汇总范围各自标明。一次维护可以填写一条记录，日内多次维护可分别填写。操作重复提交只保存同一条；请勿为同一次投入主动填写多条。

更正时填写原因。新记录替代原记录参与汇总，原始日期、耗时、说明和后续更正保留。移出本周的记录不再计入本周；在更正链上继续修改最新记录。多人并发修改时，旧版本或已被替代的记录会拒绝保存，先刷新并核对最新记录。

只有家长可操作；孩子不可读取或填写，跨家庭请求拒绝。记录随学生JSON和全家ZIP导出，并随学生或家庭删除；恢复旧备份必须应用独立删除清单。

数据表 ParentBurdenRecord 使用家庭、学生与被替代记录的外键及唯一替代索引。字段包括实际投入日期、类别、家长填写分钟、说明、记录人、服务器保存时间、被替代记录身份和更正原因。旧数据库升级不推算或填充历史投入；回滚该迁移会删除新表，应先保存备份与需要的导出。

接口：GET/POST `/api/v1/students/{id}/parent-burden`，POST `/api/v1/parent-burden/{id}:correct`；周报 `/api/v1/students/{id}/weekly-summary` 含 parentBurden。写入沿用授权、幂等、家庭版本与审计边界。无记录表示缺证据，不把某些天的平均值推广到整周或全家。
