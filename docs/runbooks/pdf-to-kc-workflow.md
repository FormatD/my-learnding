# 从 PDF 到 KC 和测试题的操作步骤

## 概述
将 mixed-operations.pdf 教材内容转换为知识组件（KC）和测试题，并发布给学生使用。

## 操作步骤

### 1. 导入 PDF 来源
**位置**: 辅助建库 → 第 1 步 · 准备并校对来源 → 导入文本型 PDF

**操作**:
- 点击"选择私有来源文件"按钮
- 选择本地 PDF 文件（如 mixed-operations.pdf）
- 系统自动解析 PDF 并提取文本
- 解析完成后，来源出现在"第 2 步 · 选择来源，生成候选"列表中

**结果**: 
- 来源保存成功，显示指纹（如 020404a9db00）
- 系统自动创建 ParsePDF 任务进行解析

---

### 2. 生成候选 KC
**位置**: 辅助建库 → 第 2 步 · 选择来源，生成候选

**操作**:
- 在来源列表中找到已导入的 PDF（如 mixed-operations.pdf）
- 点击"验证候选流程"按钮
- 系统使用本机模型或模拟流程生成候选 KC

**结果**:
- 候选生成任务完成，状态显示"处理完成"
- 在"3 · 候选生成与召回"阶段可以看到任务记录
- 系统自动提取能力定义和测量范围

---

### 3. 审核候选 KC
**位置**: 辅助建库 → 候选逐项审核

**操作**:
- 在"逐项审核"区域找到生成的候选（如 "Mixed Operations Practic"）
- 点击"核对此候选"按钮
- 查看候选详情：
  - 能力名称
  - 独立可测行为
  - 测量边界与排除范围
  - 来源片段
- 选择审核结果：
  - **接受为草稿**: 创建新的 KC 草稿
  - **关联已有能力**: 链接到现有 KC
  - **拒绝**: 不采纳此候选
- 点击"确认审核"

**结果**:
- 候选状态变为"已接受"
- 系统自动创建内容草稿
- 在"内容与发布"页面可以看到新草稿

---

### 4. 编辑内容草稿并添加测试题
**位置**: 内容与发布 → 草稿与审核

**操作**:
1. 找到 Builder 创建的草稿（如 "Builder 审核草稿 · Mixed Operations Practic"）
2. 点击"编辑"按钮打开草稿编辑器
3. 查看并完善 KC 定义：
   - 能力名称
   - 能力学科（如：数学）
   - 适用年级范围
   - 能力领域、复杂度、认知层级（可选）
   - 独立可测行为（只读，来自候选审核）
   - 测量边界与排除范围（只读，来自候选审核）
4. 添加测试题：
   - 点击"新增测量题"按钮
   - 填写题目信息：
     - **题干**: 题目文本（如"计算：25 + 15 × 3"）
     - **参考答案**: 正确答案（如"70"）
     - **判分方式**: 精确数值/家长判分/精确文字/多步骤
     - **难度**: 简单/中等/较难
     - **讲解说明**: 解题步骤和原理
     - **提示内容**: 给学生的提示
     - **如何产生能力证据**: 整题只测量一个能力/只按家长观察到的步骤/不产生能力证据
     - **测量能力**: 选择关联的 KC
     - **教学覆盖权重**: 默认 1
5. 重复步骤 4 添加更多题目
6. 点击"保存并退回待审核"

**结果**:
- 草稿保存成功，版本递增
- 显示"草稿已保存，需要重新审核"提示
- 草稿状态变为"草稿 · 版本 X"

---

### 5. 发布内容
**位置**: 内容与发布 → 草稿与审核

**操作**:
1. 找到待发布的草稿
2. 点击"审核答案与映射后发布"按钮
3. 系统验证：
   - 所有题目都有答案
   - 所有题目都关联了能力
   - 能力定义完整
4. 发布成功后，草稿变为"已发布 · 版本 X"
5. 在"已发布版本"区域可以看到新版本

**结果**:
- 显示"内容已发布，可以绑定学生"提示
- 新版本出现在"已发布版本"列表
- 版本有唯一指纹（如 cadcb794251d）

---

### 6. 绑定学生
**位置**: 内容与发布 → 已发布版本

**操作**:
1. 找到刚发布的版本（如"内容版本 2"）
2. 点击"绑定当前学生"按钮
3. 系统将当前选中的学生（如 Rachel）绑定到此版本

**结果**:
- 显示"已绑定；新计划将使用这个版本"提示
- 按钮变为"当前学生已绑定"
- 旧版本显示"绑定当前学生"按钮（可切换）

---

### 7. 创建学习计划（可选）
**位置**: 进度与计划

**操作**:
1. 点击左侧导航"进度与计划"
2. 点击"准备今日计划"或"发布今日安排"
3. 系统根据已绑定的内容版本生成学习任务
4. 学生可以在"今日学习"页面看到任务

**结果**:
- 学生可以开始学习已发布的 KC 和测试题
- 学习证据会记录到系统中

---

## 完整流程总结

```
PDF 导入 → 解析提取文本 → 生成候选 KC → 审核候选 → 
创建草稿 → 编辑草稿（添加测试题）→ 保存草稿 → 
审核发布 → 绑定学生 → 创建学习计划 → 学生学习
```

## 关键注意事项

1. **来源校对**: PDF 解析后需要人工校对，特别是扫描件的除号、竖式和阅读顺序
2. **候选审核**: 系统生成的候选 KC 需要人工审核，确认能力定义和测量范围
3. **测试题质量**: 题目、答案、讲解需要仔细核对，确保准确性
4. **版本管理**: 每次修改都会创建新版本，旧版本保留快照
5. **学生绑定**: 只有已发布并绑定的内容才会出现在学生学习计划中
6. **证据追溯**: 所有操作都有记录，可以查看审核记录和来源对照
