# 家长调整计划草稿

在“进度与计划”填写“本次计划调整原因”，再使用上移、下移、锁定/解除锁定或“移除可选任务”。原因最多1000字，保存后清空；切换到另一份草稿也不沿用旧原因。调整只改变草稿，明确发布后才应用到孩子的活动计划。

已完成、进行中和必做任务不能移除。锁定的可选任务也不能直接移除；先填写原因解除锁定，保存成功后，再填写移除原因并移除。移除仅从草稿清单拿掉任务，不删除任务或旧发布记录，不缩减最初发布任务的完成率分母。

保存前页面保留原顺序和锁定显示，只有接口成功后才更新。如果数据已被另一页面更改，会拒绝覆盖；使用“刷新当前计划”核对最新顺序、锁定与状态，再明确调整。保存失败保留所填原因，不显示为已完成保存。

后台状态检查取得的新版本不能替代打开计划时的版本。调整和发布使用计划读取时取得的独立版本，再由服务端验证；无关轮询不会允许旧计划页面覆盖其他人保存的数据。其他家庭操作也可能改变家庭版本，因此遇到冲突时应刷新核对。

新原因、请求/实际生效清单和移除身份随学生关联审计保留，可在每周回顾查看；学生导出包含说明，删除和备份恢复沿用学生隐私边界。重复同一幂等请求不多记一次。

接口 POST `/api/v1/plans/{id}:adjust` 需要当前读取版本的 If-Match、幂等键、具体原因、无重复的有效taskIds以及其子集lockedIds；null清单字段、未知身份或无效锁定身份拒绝。仅草稿允许调整。锁定/必做/已执行任务的保护由服务端执行，不能通过直接请求绕过。
