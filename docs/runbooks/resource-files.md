# 私有学习文件

在“内容与发布”编辑草稿的讲解资源，可上传10 MB以内的PDF、PNG、JPEG、WAV或MP3。上传只保存家庭私有文件；须核对来源、许可、内容与能力关联，可用“核对已关联文件”查看实际文件，再保存草稿并审核发布。服务检查文件签名、大小和摘要，不解析音视频教学质量，不替代许可核对，也不调用模型。普通错题图片和原始来源文件不能直接作为此入口的学习文件。

上传会校验编辑器捕获的家庭版本。上传期间不能保存或取消；本次上传成功只推进当前编辑器版本。另一页面先修改家庭内容时上传返回412，之后修改时保存返回412，不能靠其他读取绕过冲突。离开页面不会把响应关联到其他草稿。移除关联只修改当前草稿，不删除历史文件；已发布材料更新需新的资源修订。

家长在计划草稿的“纸笔或讲解活动”选择“计划版本讲解材料”，也可保持自填纸笔活动。选项来自该计划的固定发布版本，任务保留ResourceId、ResourceRevisionId和ReleaseId。文件入口由服务器生成，不接受任意文件ID或新发布替换旧任务。自动生成的讲解任务同样固定选中资源。发布计划后，孩子在自己的当天任务内打开学习资源；普通`/files/{id}`仍不向孩子开放。版本撤回后文件入口拒绝访问；既有题目会话的继续规则不变。

- POST `/api/v1/content/resource-files`（保留兼容入口）：ContentEditor，`{name,mimeType,base64}`，正常同源、幂等键及If-Match；成功201返回文件元数据、内容摘要和fileSnapshotHash。
- GET `/api/v1/plans/{id}/resources`：Parent，读取固定计划内容版本的资源；不是文件下载授权。
- GET `/api/v1/tasks/{id}/resource-file`：本人孩子或家长，活动已发布计划，孩子还要求当天；核对固定发布、资源独立修订、文件用途/家庭/元数据快照、实际字节摘要与签名。支持字节范围下载；OpenAPI声明可选Range、206二进制和416空响应/Content-Range，越界范围不会生成业务问题JSON。未发布/非当天409，外属任务404，文件/快照不一致或版本撤回422。没有绑定文件的任务404。

Resource中新增FileId、FileSnapshotHash；任务新增两项可空资源引用；PrivateFile新增Purpose。旧记录保持NULL，序列化省略这些NULL新增字段，旧资源/任务摘要不补写。FileSnapshotHash冻结文件ID、名称、媒体类型、内容摘要及LearningResource用途，审核、发布和打开均核对实际文件。

学生导出包括其绑定发布和历史计划发布引用的文件；家庭ZIP包括原字节、摘要和用途。学生删除保留家庭共享学习文件，家庭删除移除全家文件。恢复执行最新删除清单也遵循该规则；没有Purpose列的旧备份采用原删除逻辑。上传后未关联的文件暂留在家庭存储和完整家庭导出/备份中，没有自动清理或资源文件单独删除入口。

`tests/resource_file_acceptance.py`在真实隔离数据库中验证版本冲突、五种签名、普通私有附件排除、固定引用、孩子/家庭/日期权限、范围读取、导出、字节/元数据损坏和撤回。实际加密备份恢复逐行核对文件和任务引用，最新学生删除清单保留共享材料、家庭删除清单清除全家文件。该同盘临时恢复不证明独立盘、真实灾难恢复时间或设备播放性能。浏览器`resource-files.spec.ts`验证实际上传中禁止保存、上传后保存、固定计划选材、孩子下载与390宽度布局；可在隔离接口验收中设置RESOURCE_FILE_BROWSER=1执行。


## 受限上传与恢复

页面上传现在依次申请凭据、传原始字节、确认完成。POST `/api/v1/files/upload-tickets`声明名称、媒体、大小、SHA-256和用途；201返回文件ID、上传地址、15分钟凭据及该请求提交的家庭版本。凭据仅供本人账号、当前家庭和指定文件使用，仍需登录、同源/CSRF、幂等键及If-Match；学习材料与PDF须ContentEditor，普通图片附件须Parent。GET `/api/v1/files/upload-tickets/{id}`只返回本人元数据和状态，不含凭据或暂存字节。

PUT `/api/v1/files/uploads/{id}`提交`application/octet-stream`，另带`X-Upload-Credential`。服务器核对声明大小、SHA-256与格式签名；此时只是暂存，普通文件入口不可读。POST `/api/v1/files/{id}:complete`再次独立核对实际暂存字节，事务内生成一个私有文件并清空暂存；返回学习文件快照摘要和本次提交版本。凭据不放入URL，数据库只存摘要；含原凭据的幂等结果使用本地数据保护密钥加密保存。旧直接上传接口保留原行为。

编辑器在内存保留各阶段请求标识，重新选择同一原文件可继续未确认阶段。完成成功但响应丢失时，同一请求返回原文件和原提交版本，不重复生成文件；不能把较新的全局版本当成编辑器已确认的版本。离开草稿后清空重试状态，不持久化浏览器凭据。权限撤销使旧会话失效，重新登录后仍按当前权限检查缓存重试。凭据过期返回410；默认每60秒清理到期暂存字节。已完成但未关联的文件仍保留，不自动删除。

家庭ZIP只包含上传状态元数据，不包含凭据摘要和暂存字节；加密数据库备份包含完整数据库。恢复先清除会话/命令，并将未完成上传标记Expired、清空暂存，完成文件保持。旧备份没有上传表时跳过该分支。

`tests/upload_ticket_acceptance.py`使用隔离实际数据库核对大小/摘要/媒体、缓存密文、本人账号/孩子及角色撤销、完成前不可读、原字节幂等、版本冲突、实际暂存损坏、完成清空及到期后台清理。真实加密恢复核对未完成上传清空、完成文件逐字节保持；这仍是同盘演练。设置UPLOAD_TICKET_BROWSER=1运行上传完成响应丢失的实际浏览器重试，以及原学习文件保存/任务交付页面。
