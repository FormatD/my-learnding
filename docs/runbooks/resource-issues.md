# 学习资源问题报告

孩子打开已发布资源任务后，可选“资源打不开或不合适”，填写500字以内说明，再“告诉家长”。纸质材料缺页、外部资源打不开或内容不合适都可说明；系统不自动检测外部链接，也不会代替家长判断资源质量。取消不提交，失败保留输入；同一说明重试复用命令键，避免响应丢失时重复保存。返回今日任务不会把任务算作完成。

家长在当前学生“今日学习”的“资源问题”查看最近50条，可刷新。报告保存当时任务标题、材料引用、原链接、发布版本、说明与时间。更早报告仍在学生私有导出的studentAudit内，Action为ResourceIssueReported，Details保存原报告。页面没有已解决标记，刷新不会消除报告；家长按实际核对结果调整任务或重新审核内容，并记录对应调整依据。系统不自动换绑、撤回版本或修正掌握证据。

POST `/api/v1/tasks/{id}/resource-issues`，请求`{reason}`，成功201返回Id、CreatedAt、Issue；原任务和证据不变。要求正常同源和幂等命令约定。只接受非题目任务；任务必须仍在已发布活动计划中，孩子还要求当天及本人学生。未发布/移出活动计划409 TASK_NOT_ACTIVE，空白/超过500字422 REASON_REQUIRED，题目任务422 NOT_RESOURCE_TASK，其他家庭或其他孩子对象404。

GET `/api/v1/students/{id}/resource-issues`仅Parent可读，返回按CreatedAt降序、Id升序的最近50条报告数组，不是全历史分页接口；孩子403，跨家庭学生404。报告为追加审计记录，不提供修改原报告或自动完成任务的命令。既有学生/家庭删除、学生导出与数据库备份路径使用真实审计记录。

`tests/resource_issue_acceptance.py`接入实际OpenAPI隔离服务回归；`src/web/tests/resource-issues.spec.ts`覆盖孩子提交、取消、家长读取、任务/证据保持和幂等。真实外部链接/家庭设备可用性仍需实际试用，不由原创纸质材料测试代替。
