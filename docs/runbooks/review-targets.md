# 复习测量目标与规则升级

当前review/3保留review/2的实际测量目标校验，并加入明确家长确认。知识点复习必须实际测量稳定目标；NoEvidence、零份额、前置/背景关联及无测量模式不能代表原目标。匹配目标的首次复习作答可记录执行，但只有可信判分、未看答案或使用提示、该目标全部可测部分独立正确，才推进阶段。观察步骤缺失不推定正确；同一目标的某一步失败不能由另一步正确抵消。错题整题复习同时核对步骤提示记录。

当前整题通过率仍要求整题独立正确，知识点日程可以依据该目标全部可测步骤推进。周报明确区分两种口径。实际题目不再测量任务原目标时，保留遇题和已判分分母，不计原目标独立通过，显示“测量目标已变化，请家长核对”。覆盖率也不把这种作答记成原知识点日程执行。

家长在“证据与复习”的“核对复习目标变化”查看原任务目标、当前有效题目及实际测量知识点，选择“保留原目标，重新安排复习”或“本次按实际测量目标核对复测”。后一种须明确选择当前真正测量的知识点。填写依据后预览，再确认；不自动转移掌握度，原目标始终保留待复习。判分、映射、评估、作答边界或上一确认变化时旧预览412，须重新预览。

确认返回202，仅表示原测量快照、选择、实际序号和说明已保存并提交真实必需学习结果来源。后台沿固定评估目标消费，在同一事务提交新状态、日程、原事件回执、应用事实及消费边界；页面的后台待同步状态来自实际查询。只有对应日程已到期且目标可测部分可信、独立正确才推进实际目标。保留原目标的确认不会使本次通过原目标。周报区分尚待确认、已确认保留原目标、明确确认实际目标的独立通过；整题通过率仍要求整题独立正确。

同步后点击“去安排明日复习”，进入学生时区的明日计划；可调整“计划日期”，按当前正式内容生成新草稿并明确发布。今天已完成、进行中或锁定的旧任务保留，原目标使用实际测量它的当前正式题目。缺少内容时原目标保持缺口，不能用确认冒充完成。确认不会自动修改或发布当前计划。

ReviewTargetConfirmation仅追加，保存原任务、原目标、实际采用目标、题目/映射/更正来源及原JSON摘要、确认人和说明；数据库核对实际首次复习答案、家庭/学生/任务归属、当次家长权限、发布引用与可测目标，并禁止原地修改。再次选择追加新确认；有效映射再次变化后旧确认不自动沿用，原记录仍保留。学生导出及全家庭导出包含实际确认记录，隐私删除按家庭/学生关联清理。

规则及确认依据进入实际评估输入和assessment-prefix/3摘要。旧规则检查点不作为review/3的增量前缀；确认变化也使前缀重新核对。下一次实际评估从原始记录完整重算为新世代，旧检查点、证据和复习记录保持原样；不提前改写全部学生活动指针，不回填历史缺口。确认仅改变复习归属，原发布任务的稳定关联不改写，既有测量证据不转给另一知识点。
