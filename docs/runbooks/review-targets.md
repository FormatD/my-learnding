# 复习测量目标与规则升级

review/2在保留发布任务原关联的前提下核对当前有效题目映射。知识点复习必须实际测量任务的稳定目标；NoEvidence、零份额、前置/背景关联及无测量模式不能代表原目标。匹配目标的首次复习作答可记录执行，但只有可信判分、未看答案或使用提示、该目标全部可测部分独立正确，才推进阶段。观察步骤缺失不推定正确；同一目标的某一步失败不能由另一步正确抵消。错题整题复习同时核对步骤提示记录。

当前整题通过率仍要求整题独立正确，知识点日程可以依据该目标全部可测步骤推进。周报明确区分两种口径。实际题目不再测量任务原目标时，保留遇题和已判分分母，不计原目标独立通过，显示“测量目标已变化，请家长核对”。覆盖率也不把这种作答记成原知识点日程执行。

家长可在证据与复习中核对原作答、有效判分和映射更正来源。现有映射更正会预览并保存家长确认，但复习目标迁移的独立确认及后续重新安排流程仍待开发；当前提示不是已经完成确认，也不会自动把结果转给另一目标。

规则变化进入实际评估输入及检查点前缀摘要。保存了review/1的旧检查点不作为review/2的增量前缀。下一次实际评估从原始记录完整重算为新世代，旧检查点、证据和复习记录保持原样；不提前改写全部学生活动指针，不回填历史缺口。
