# 往周回顾与调整依据

在“每周回顾”选择“周报结束日期”，点击“查看所选一周”。范围是所选日期及此前6天，默认今天；前一周/后一周按7天切换，“返回最近一周”回到今天。日期依据学生时区，不能选择未来。

任务完成率按所选日期内的已发布计划和本次查看时的任务状态汇总，不是当年某刻的历史状态快照。后续完成或顺延的任务仍可显示当前状态。最初发布的任务分母保持，最终活动任务另算；草稿不会进入完成率。没有已发布计划的日期显示缺口，不表示100%完成。

展开“原始、最终及中间版本任务”，可查看任务属于哪些日期/发布修订，以及哪些是最初计划、最终活动或中间版本。同一个固定任务在多个修订中保留身份，不按修订次数重复计数。当前已知实际耗时是这些任务的累计记录，不等同于所选周内实际发生的学习时钟。

新计划调整会保留具体原因、调整前顺序、请求顺序、实际生效顺序、被移除任务以及锁定身份。预算处理若继续移除可选项，以实际生效清单为准；幂等重放不会多记一次调整。已发布与仅草稿调整各自注明。

家长顺延记录原日期的移除修订、目标日期和家长填写的原因；跳过、开始、完成、结束等新执行记录保留前后状态和填写的说明。“执行与跳过说明”显示的是所选计划任务当前可追踪的事件，其实际发生日期可能晚于计划日期。历史只保存摘要的记录无法恢复具体原因，也不推算出一条说明。

“当前到期复习”始终反映今天的待办，不代表所选往周的历史到期覆盖率或通过率；页面明确标注。往周家长投入只汇总相应日期的最新有效填写记录，日常维护和集中审核分开；没有填写保持缺口。四周试用及其完整指标仍需真实记录验收。

GET `/api/v1/students/{id}/weekly-summary?end=YYYY-MM-DD` 返回 start/end/currentDate/observedAt/timeZone、original/adjusted、所有已发布任务的修订归属、adjustments/transitions、parentBurden 和当前待办。所有查询在同一个可重复读快照完成；与代码同源生成 WeeklySummary 接口结构。只有家长可查，跨家庭404，孩子403。

新审计使用既有Audit表的 PlanAdjusted/TaskTransition 类型，以可空StudentId和家庭/学生外键关联，随学生JSON、全家导出和数据库备份保留，删除学生会级联清除其具体说明。普通家庭摘要不推算学生关联。升级只按原始具体说明中的真实学生/计划建立链接；已无所属学生的具体私人说明清除，不重建原理由。恢复旧备份时，原未关联外键的具体说明也按原学生/计划与独立删除清单清除，不能仅依赖新外键。没有改写旧任务、证据或作答。迁移回滚会丢失新关联约束，回滚前应保存需要的导出及备份，并继续使用支持旧具体说明清理的恢复工具。
