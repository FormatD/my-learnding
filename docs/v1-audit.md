# V1 阶段性范围核对（2026-10-03）

基线是[设计v1.1](design/baseline-v1.1.md)，目标保持完整V1。用户明确先本地运行、模型稍后接入，正式单元为北师大版《混合运算》。当前默认三年级、30分钟可修改，印次和真实使用条件仍待核对。此表区分实现入口与验收退出条件；源码存在或历史用例通过不等于整体已完成。本轮没有重跑全部历史用例，也不把测试入口当作本轮执行证据。

## 里程碑与交接

- M0：工程基线、规则及最小内容可测试；本轮新增保存的[JSON交接夹具](../tests/fixtures/README.md)，实际45/45规则检查通过。
- 资源修订补齐：后续规则46/46，资源接口3组、实际页面编辑/重新审核发布1/1及既有接口37项回归通过；独立修订前旧格式仍兼容，已发布修订不能覆盖或降级。资源建议流程未完成。
- 映射建议后续：规则49/49、映射接口7组、真实页面校正/整批失败/过期拒绝/发布1/1通过；实际契约88路径/119结构，51表/24迁移。教材和质量退出条件没有因本地流程通过而关闭。
- M1：本地人工闭环存在；“真实平板完整一天”的退出条件未证明。
- M2：规则、版本、更正、故障及日期流程有针对性检查；完整运行环境退出条件不推定通过。
- M3：规则草稿/人工覆盖/周报存在，临时空库恢复可验证；后续含映射记录的真实快照51表/33,559保留记录逐列一致（3.20秒）；独立盘及正式切换仍欠缺。
- M4：本地Mock能力候选与映射建议辅助已有人工流程和版本检查；不满足真实模型评测及E12正式映射质量退出条件。
- M5：周报可记录维护投入、预算、复习、掌握和待处理信息；连续四周真实使用及故障记录仍无充分证据。

§16.5交接：ADR在`docs/adr`，同源OpenAPI在`docs/api/openapi.json`，实际字典在`docs/data-dictionary.md`及`docs/data/schema.json`，迁移在服务项目，合成回放样例在`tests/fixtures`，内容及运维说明在`docs/runbooks`。这些材料已可定位，不关闭各模块的完整Definition of Done。具体历史AT证据和限制见[验收记录](acceptance.md)。

## 后续推进顺序

继续统一手工映射路径及模型适配、结构校验与费用/超时的受控入口，固定评测材料和人工标注交接；不以选用Mock缩小K1最终目标。投影增量一致性及通用Job语义须另行作实现/决策核对，不将现有精简模型默认为完整设计。

实体设备、教材人工审核、独立盘以及连续四周观察需要真实输入或时间；这些是开放退出条件，不能使用测试家庭、回填日期、模拟网络或临时演练耗时代替。V1目标继续进行。
